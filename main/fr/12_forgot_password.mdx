---
title: Mot de passe oublié
description: Comment réinitialiser votre mot de passe dans l'application employé.
---

Si vous avez oublié votre mot de passe, vous pouvez facilement le réinitialiser.

## Étapes

1. Ouvrez l'application et appuyez sur "Mot de passe oublié"
2. Saisissez votre adresse e-mail enregistrée
3. Vérifiez votre boîte de réception
4. Suivez le lien dans l'e-mail pour créer un nouveau mot de passe
