Ce guide pas à pas relie les images produit existantes aux instructions détaillées. Les images et les vidéos peuvent montrer une version antérieure de l’interface ; pour les parcours de clics et les champs obligatoires, utilisez les textes liés.

## Déroulement pour les responsables de planification

1. [Trouver le projet](/main/fr/02_projects_dashboard) : vérifier le statut, la recherche et les filtres.
2. [Créer un projet](/main/fr/03_create_project) : **Projets → Créer un projet**, saisir les informations obligatoires et attribuer des jours à chaque site.
3. [Planifier le projet](/main/fr/04_project_planning) : vérifier séparément les rôles, les créneaux, les pauses, le besoin et les filtres.
4. [Choisir la publication](/main/fr/04a_publication_and_allocation) : décider de la publication seulement à l’étape 3. **Affecter sans publication** est une action active ; ensuite, vérifier l’état à l’étape 4.
5. [Faire inscrire de nouveaux collaborateurs](/main/fr/05_employees_dashboard#inviter-des-collaborateurs-à-sinscrire) : **paramètres**, tout en haut à côté du nom de l’agence près du logo, **copier le lien d'inscription**. Ne pas confondre avec une demande de mission.
