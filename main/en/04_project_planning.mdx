title: "Project planning"
---

In step **2 – project planning**, you define **which function is needed at which location at what time and with how many people**. A saved project with locations and days, as well as editing rights, is required. Planning is not yet publication and not yet assignment.

## Create a role at the correct location

1. Open your project and click step **2**. Check the project name and day headings.
2. Expand the desired location. **Expand all** helps when there are multiple locations and roles.
3. Click **Add new role** under this location.
4. Fill in **role name** in at least one language. If needed, add **Role Description**, **cost center** and **department**. The description can be formatted and translated.
5. Click **Save**. Check that the role appears under the intended location. If a role name has already been used at the same location, an error message appears; use a unique name or edit the existing role.

A role describes the function, for example reception. It is neither a single person nor an assignment that has already been booked. A new role starts without an applied employee filter; an initial filter display of 0 therefore does not automatically mean that your entire pool is empty.

## Enter shifts, times and breaks

1. Open the role and check the first shift. When a role is newly created, the interface initially shows **08:00–16:00**; the break value comes from the saved response. Do not take over these values without checking them.
2. Edit the start and end times in the time fields in **HH:MM** format. Leave the field after entering the full value and check the display.
3. Enter the **break time** in **minutes**.
4. If specific break intervals are required, open the break button next to the break field. In the **Split Shift - break(s)** dialog, maintain the start/end times of the breaks and add or remove rows. If break intervals already exist, the simple minute field is disabled.
5. Via **Enter shift name**, you can maintain and save a custom shift name for each language.
6. For an additional time period, click **Add new shift**. If a shift already exists, the new one initially starts at the end of the last shift and initially has **the same start and end time**. Therefore set both times deliberately; the additional entry is not yet a finished shift.

**How to tell it worked:** The correct role contains the desired shifts, times, breaks and names. Check them after reopening planning, especially after error messages or a connection interruption.

## Set staffing requirements by date and shift

1. In the shift row, find the column for the desired date.
2. Enter the required regular number of people in the numerical staffing cell. Check each combination of location, role, shift and date separately.
3. If additional overbookings are intended, click the **+** next to the requirement. Enter **Number of overbookings** and confirm **Save**. Overbooking is a separate value and not the same as the regular requirement.
4. Then check both the staffing number and the separate overbooking value.

**Important:** A role that has been created, a shift, or a matching employee filter does not automatically assign a required employee and does not book anyone. The staffing cell shows the regular requirement separately from overbookings. If a requirement is inactive, its input cell is disabled; archived projects and missing editing rights can also prevent changes.

## Determine suitable employees with the role filter

1. Click the filter icon for the specific role; if no filter has been saved, its tooltip indicates that no filter has been applied yet. Make sure not to accidentally use the multi-edit function for other roles.
2. Check the criteria or load an existing filter template. A new role has no saved filter yet; when it is opened for the first time, a new filter is prepared in the agency/customer context.
3. Select the criteria required for the assignment. Commonly helpful are **Employee lists**, **Customer pool**, **Skills** (training, professional experience, languages), **Address** with distance to the location, and **General availability**.
4. When there are multiple lists or criteria, check the respective option for "all": it may narrow the selection further. Also check exclusion lists and people manually deselected; a list name alone does not describe the entire filter.
5. Check the suitable number of employees and, if necessary, the result list. **General availability** offers separate options to exclude stored unavailability and to more strictly exclude unavailable or conflicting shifts. Choose the option that matches your planning goal.
6. Click **Apply selected filter**. Only then is the filter saved for this role and the display updated. If in doubt, open it again and check the criteria.

The number of matches is a selection aid, not a commitment and not a confirmed staffing. In **Self Service**, the filter is limited to the project customer's pool, even for agency users. A loaded template there does not mean access to the entire agency pool.

## Additional details per role

Open the corresponding icons directly on the role and check the details before publication:

- **wage information** and **expenses:** Check assignment-related compensation and expense information. Visibility and editing may be restricted in Self Service for customer users.
- **Dress code:** Store requirements for the specific role.
- **Document upload:** Add related assignment documents and check the assigned file.
- **Rate group:** Check the name as well as the minimum and maximum hourly rate. The rate group dialog is not the same as the employee filter; for Self Service customer users, this view is read-only.

This guide describes how to use the system, not how wages or contractual terms are set in business terms. Clarify the correct values internally before communicating them to employees.

## Edit multiple roles and use templates

Open **Edit multiple roles** and then select the desired roles using the checkboxes shown. The actions there for wage information, expenses, clothing, documents, rate group or filter affect the selected roles. Before each change, check the scope of the selection; for a single role, use its own icons.

Under the location, you can use **Load template** to take over a role. **Save as project template** at the top in step 2, by contrast, saves a project template. The differences and the checks after loading are described under [Templates and reuse](/main/en/06_templates_and_reuse).

## Final check and typical errors

Before **Next**, check for each location and day: role, shift time, break, regular requirement, overbookings, applied filter and the intended compensation/assignment details. If there are many days, you can scroll sideways in the date row.

- **Filter shows 0:** Was the filter actually applied? Are the criteria too narrow, the wrong lists selected, or people manually excluded? Also check the client pool in Self Service.
- **Role exists, but no requirement:** The number must be set explicitly for each shift and day.
- **Break field locked:** First check the break intervals under **Split Shift - break(s)**.
- **Changes not possible:** Check archiving and editing rights; a visible role is not proof of write access.

**Next** opens step **3**. Only there do you decide on [publication or assignment without publication](/main/en/04a_publication_and_allocation).
