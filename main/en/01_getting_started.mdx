bejoo is designed to help you plan projects, structure staffing needs, and prepare execution in one place.

## Typical workflow

A typical workflow looks like this:
1. Open the Projects dashboard
2. Create a new project
3. Add location and dates
4. Define the roles needed for the project
5. Add or adjust shifts
6. Review staffing requirements
7. Use the Employees area to support staffing decisions
8. Reuse templates where recurring setups make sense

## Main areas of the platform

### Projects
Use this area to see existing projects, open a project, or start a new one.

### Project planning
Use this area to structure the project: locations, dates, roles, shifts, and staffing setup.

### Employees
Use this area to inspect your available workforce and work with filtering and candidate selection.

### Templates
Use templates when your team repeats similar project or role setups.

## Good practice
- Create the project with clean basics first
- Keep roles and shifts structured before staffing starts
- Standardize recurring setups with templates
- Use filters to narrow the candidate pool instead of searching manually
