## Project
The overall assignment, campaign, or event that is being planned.

## Location
The place where work happens.

## Date
A project day connected to one or more locations.

## Role
A staffing function within a project, for example hostess or promoter.

## Shift
A concrete time block for a role.

## Planning
The structured setup of the project before execution.

## Employees area
The area where teams inspect and narrow the available talent pool.

## Template
A reusable setup that helps teams repeat common work faster and more consistently.
