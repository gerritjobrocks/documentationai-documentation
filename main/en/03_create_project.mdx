With these steps, you create a standard agency project as a planner. Have the client, project type, responsible agency contact, location, and project days ready. You need the rights to view, create, and edit projects.

## Getting started and required information

1. Open the **Projects** submenu on the left and select **Create project**. You will land in step **1**, the basic information.
2. Enter a **project name** in the desired language tab **EN**, **DE**, **FR**, or **IT**. At least one language version must be filled in; a maximum of **100 characters** is allowed per name. You do not have to fill in all four languages.
3. Select the **project type** and **client** from the available entries.
4. In the agency contact area, select at least one **Project Manager or HR Manager**. Both may be set, but not both left empty.
5. Add at least one actual location and assign **at least one date to each added location**. A search text alone is not yet a selected location.
6. Check the additional settings below and click **Next**. Confirm the notice that the client can no longer be changed after saving only if the selection is correct. An additional confirmation appears when newly added past dates are involved.

**Recognizing success:** After successful saving, step **2 – Project planning** opens. Roles, shifts, and staffing requirements are recorded there. Filling in the basic information does not publish any jobs yet.

## Name, description, and project image

- **Project name:** Choose a name that helps your team find the project again. Maintain additional language versions in the language tabs if needed.
- **Project description:** Optional formatted text, also per language. Describe the task, meeting point, or process. The translation button appears when content exists in another language; check the result before using it.
- **Project image:** Optional. In the image area, you can upload an image; for a custom project image, there are delete and enlarge options. A displayed agency logo does not mean that a custom project image has already been uploaded.

## Client, contacts, and visibility

| Field | What you enter or select | Effect and notes |
| --- | --- | --- |
| **Project type** | Select an existing type; typing and Enter/Tab can open the creation path. | Required, internal, and not visible to employees. In the dialog, a name with a maximum of 50 characters is required. |
| **Parent project** | Select another project if needed. | Optional internal assignment; not available in Self Service. |
| **Project Manager** | Select or create an agency contact. | In agency mode, this field or **HR Manager** must be filled in. The separate **visible to employees** switch controls whether the project management is shown. |
| **HR Manager** | Select or create an agency contact. | Internal contact assignment; in agency mode, this alone can satisfy the agency-contact requirement. |
| **Client** | Select or create the client commissioning the work. | Required. Cannot be changed after the first save. **visible to employees** controls the client name, not a client user's access to the project. |
| **client contact** | Select or create a contact for the selected client. | Optional in agency mode and internal. In Self Service, the client contact is recorded in the **Project Manager** field. |
| **Client Buyer** | Select a client user or invite one through the dialog provided. | Assigns the project to a client user. Whether this user or other client users can see it additionally depends on their view rights and department access. In Self Service, separate rights apply for your own versus all self-service projects; access to all orders does not replace these. This is not employee registration. Client users themselves do not see this selection. |
| **Time Tracking Responsible** | Select one or more people or invite them through the dialog provided. | Multiple selection. **visible to employees** is a separate switch and controls whether these responsible persons are shown. |

**New contacts:** The contact dialog requires first name and last name (up to 24 characters each) as well as a valid email address. A mobile number entered there may be no more than 16 characters. Pay attention to whether you are currently creating an agency contact or a client contact.

**New client:** The client name is required. You can add a legal client name, company website, street, house number, additional address line, postal code, city, and country; for Switzerland, canton also appears. The client address does not replace the selection of the assignment location.

**Invitation dialogs are active actions:** For a Client Buyer, first name, last name, email, and language (**EN/DE/FR/IT**) are requested, and departments if applicable. For the person responsible for time tracking, role selection is added. **Save** starts a user invitation here. Do not use the data of someone who is only supposed to register as an employee for this.

## Internal assignment and billing context

| Field | Input and behavior |
| --- | --- |
| **Project no.** | Optional, maximum 99 characters. If the number is already in use, a confirmation prompt appears; check the project named there before you continue. |
| **Order no.** | Optional internal information, maximum 99 characters. |
| **Cost center** | Enter a free value or select a suggestion. If an existing project shows **Multiple cost centers in use.**, check the individual roles instead of assuming a single project cost center. |
| **Department** | Select a client department or create one by typing and pressing Enter. If **Multiple departments in use** is shown, check the assignment for each role in planning. |

## Set booking and automation options intentionally

| Switch | Meaning for your process |
| --- | --- |
| **Automatic invitation upon activation** | Allows invitations for newly activated employees to matching open/ongoing projects with open future staffing requirements and a matching role filter. This is not publication on save and not a confirmed assignment. |
| **Self-booking** | Decide whether employees should book themselves into suitable assignments instead of only applying. Registration and self-booking are different processes. Check the setting before publication. |
| **Automatically republish when an assignment becomes available again** | Option for republishing when assignments become available again. Only activate it if this automatic follow-up flow is desired. |
| **Automatically close** | Closes the staffing requirement of a fully accepted shift based on confirmed or self-booked assignments. It does not archive the entire project. If staffing drops below the requirement again, the shift can be reopened. |
| **Cancellation by employee** | Enables the corresponding cancellation process and shows **Cancellation deadline (in days)**. When the switch is on, a deadline of at least **2 days** is required. |

**Check the default values:** In the new project form, these five switches are off and the cancellation deadline is empty. Client visibility is on; project manager and the person responsible for time tracking visibility are off. Contacts, internal assignments, and locations are initially empty. These are not guarantees for loaded templates, existing projects, or restored browser drafts: always check the values actually displayed.

## Assign location and individual days

1. In the location field, search by name, address, name as shown in Google Maps, or coordinates and select a matching result. When creating a new location, it needs a **Database Name**; the Google location name is shown separately in the dialog.
2. Check the name and the address shown below it in the added location row. **No address** is not a confirmed location; clarify the location before publication.
3. Mark the checkbox of the location for which you want to record days. It controls the calendar assignment, not the selection of employees.
4. In the **Date range** tab, select the assignment days in the calendar. Expand the location and check its date list and the displayed count.
5. Repeat this for additional locations. Remove incorrectly assigned days with **remove date** or an unneeded location with **delete location**. With multiple locations, you can move the date assignment using **Change Location** and **Add Here**.

The map also offers actions to add existing locations or create new ones. It is not only a preview. Then check the location list and the assigned days again.

## Create recurring assignment days

1. Select the affected locations and open **Recurring pattern**.
2. Set **From** and **To** for the desired period.
3. Choose the weekly or monthly pattern. Weekly, you can specify **every week**, **every 2nd, 3rd, or 4th week**, and multiple weekdays. Monthly, choose the **first, second, third, fourth, or last** desired weekday of the month.
4. Check the **preview** and the number of calculated days. Only then click **Apply pattern**. The pattern applies to the selected locations; already selected dates are retained.
5. Check the result list for each location. **Remove matching days** removes matching already selected days and is not just a preview. Then save with **Next**.

In a new pattern, selection starts weekly with every week; the period and weekly days are initially empty. Selecting a pattern alone does not yet create a saved project. For projects with **pay per assignment**, a From/To period selection is available instead; the pattern workflow applies to standard projects.

## Differences in Self Service

Use **Self Service → Create project** instead of the normal project creation flow. You need separate Self Service rights for creating, viewing, and editing.

- **Project Manager** here is a **client contact** and is required. The agency rule “Project Manager or HR Manager” does not apply here.
- **HR Manager** and **Parent project** are not shown.
- Project types are client-specific. As long as an agency user has not selected a client, project type and Project Manager cannot be selected.
- For client users, the client is already predetermined by the user context; the client selection and the Client Buyer picker are hidden.
- Location, assignment days, and the subsequent planning remain separate work steps.

## If Next does not work

First check that you have at least one name with no more than 100 characters, the project type, the client, and the correct contact for your mode. Then open **each** added location: a location without a date prevents saving. If employee cancellation is allowed, the deadline must be at least two days.

An error message while saving is not a successfully created project. A browser draft while you are entering data is also not yet a saved server project. After an unclear result, first check the dashboard before repeating the creation process. If fields are locked, check edit rights, archiving, or a pending order with your administrator.

Continue with [Plan roles, shifts, and staffing requirements](/main/en/04_project_planning).
