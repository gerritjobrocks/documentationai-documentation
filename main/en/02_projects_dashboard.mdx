title: "Projects dashboard"

The **Projects dashboard** is the starting point for planners who want to find projects, continue planning them, or create new ones. You need access to projects; viewing, creating, and editing are separate permissions.

## Find an existing project

1. Open **Projects** on the left.
2. Select the appropriate status: **Open projects**, **Ongoing projects**, **Past projects**, **Draft projects**, **Archived projects**, or **Cancelled projects**. **Draft Orders** and **Submitted Orders** are separate views; do not confuse them with project drafts.
3. Enter a suitable search term in the **Search by project, client, location** search field.
4. Select **By project** if you want an overview of the projects, or **By date** if you want to look at individual project days. Multiple daily rows do not automatically mean multiple projects.
5. If needed, narrow it down with **project type**, **Project Manager**, as well as **From** and **To**. Then click **Filter**. You can select multiple project types or project managers together.
6. Open the appropriate project from the table. Check the project name, client, location, and dates in the basic information before you change anything. The numbered steps take you to planning, publication, and staff assignment.

**Recognizing success:** You can see the project you searched for, and when you open it, its basic information. A match or a status alone does not prove that an invitation was sent or that staffing is complete.

## Show multiple statuses at the same time

In the status row, click **Filter**, select the desired statuses, and confirm with **Apply filter**. The active filter is highlighted. Clicking a single status switches back to that status view. Use **Reset filter** in the dialog to reset the selection; then confirm with **Apply filter** so it takes effect.

The selection of project type, project manager, and time period is separate from this. The **x** next to these filters clears that selection. If a search is unsuccessful, also remove the search text and check the status selection; this helps distinguish a search that is too narrow from a missing project.

## Start a new project

Open the submenu for **Projects** in the left navigation and select **Create project**. Do not look for the former separate plus button next to the menu item. If you have an existing project template, select **Load template** there.

The detailed next steps are under [Create project](/main/en/03_create_project) and [Templates and reuse](/main/en/06_templates_and_reuse).

## If something is missing or locked

- **Create project is missing:** Have a qualified administrator check the permissions for viewing, creating, and editing projects. Read-only access is not enough.
- **Project is missing:** Check the search text, status, and time period. If it remains invisible, clarify whether you are allowed to see only your own projects or all projects.
- **Project can be opened, but not changed:** Archiving, a pending order, or missing edit permission can lock editing. Do not work around this by using a second project.
- **You are working with Self Service:** Use the dedicated **Self Service** menu item and its project creation flow. Separate rights and a different client contact context apply there; see [Self Service](/main/en/03_create_project#differences-in-self-service).
